## Start here

Linux, Node.js 22+, tmux 3.4+, Python 3, and a working Codex session. Run the app as the same non-root user as tmux.

| Your goal                                     | Guide                                                                     |
| --------------------------------------------- | ------------------------------------------------------------------------- |
| Try chat and terminal without buying a domain | [Free HTTPS address](docs/FREE-TRYOUT.en.md)                              |
| Own a stable address with full web previews   | [Server, domain and HTTPS — Tencent Cloud example](docs/DEPLOYMENT.en.md) |

Vanilla frontend. No build step. One Node service. Free single-address tunnels do not include isolated HTML previews.
